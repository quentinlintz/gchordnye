# G Chord NYE

Every New Year's Eve, at local midnight, musicians all over the world take their instrument, face west, and play a G to support human-made music. This site is a homepage and countdown for that event.

This repo was built from the minimal Astro template and coded by a human.

Check the site [here](https://gchordnye.com)!

## Setup

Node 24 is the dev and CI version, see `.nvmrc`.

Install dependencies

```
npm ci
```

Start the dev server

```
npm run dev
```

Check/fix formatting

```
npm run format
npm run format:check
```

Run Astro's typecheck

```
npm run typecheck
```

Create a production build

```
npm run build
```

## Deployment

This repo is deployed on [GitHub Pages](https://github.com/quentinlintz/gchordnye/deployments/github-pages) when changes are pushed to `main`. Custom domain is managed in the GitHub Pages settings.
